# DeliverIQ Build 5 — AI Delivery Command Centre

Build 5 turns saved project data into an executive delivery cockpit.

## New capabilities
- Delivery Command Centre dashboard
- AI-generated delivery health assessment
- Attention items ranked by urgency
- Risk/issue concentration
- Milestone/dependency awareness
- KPI recommendations
- Human-readable recommended actions
- AI review API reads real project data

## Important
AI recommendations are advisory. They should be reviewed by the delivery owner before being treated as project decisions.
