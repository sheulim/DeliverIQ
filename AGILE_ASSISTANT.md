# DeliverIQ Agile Assistant

The Agile Assistant is a floating chatbot available throughout DeliverIQ.

It can answer:
- Scrum and Kanban questions
- Scrum Master coaching and ceremony questions
- Delivery Manager governance questions
- Project / Program / Portfolio management questions
- RAID, dependencies, RACI, status reporting and metrics
- Capacity, change, financial and benefits governance
- Technical/data-migration delivery questions
- Questions grounded in the user's current DeliverIQ project data
- Current questions using live OpenAI web search when enabled

Grounding order:
1. Current project data, where available and authorised
2. DeliverIQ role playbooks
3. DeliverIQ template catalogue
4. General model knowledge
5. Live web search when enabled/useful

The assistant does not silently alter project records. Advice remains advisory and organisation-specific policies must be verified.
