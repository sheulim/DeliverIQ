# DeliverIQ Build 12 — Stakeholder & Communications Intelligence

Build 12 adds stakeholder mapping and tailored project communications.

## New capabilities
- Stakeholder register
- Influence / interest classification
- Engagement strategy
- Communication preferences
- AI-generated stakeholder updates
- Executive / team / vendor / business audience variants
- Escalation message generation
- Communication history
- Programme-level stakeholder roll-up
- Human review before saving or sending externally

## Product principle
The same project status should be communicated differently to different audiences.
DeliverIQ helps adapt the message without inventing facts.
