# DeliverIQ Build 7 — Executive Reporting & Weekly Delivery Copilot

Build 7 converts live project data into executive-ready project reporting.

## New capabilities
- AI weekly delivery brief
- Steering committee summary
- Achievements
- Current status / RAG narrative
- Top risks and issues
- Decisions required
- Upcoming milestones
- Dependencies needing attention
- Next-week priorities
- Executive asks
- Status report history in Supabase
- Human review before saving generated reports

## Core principle
The AI drafts the report from current DeliverIQ project data.
It must not invent progress, dates, decisions or achievements that are not supported by the data.
The project manager remains the final reviewer.
