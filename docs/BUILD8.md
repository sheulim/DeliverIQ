# DeliverIQ Build 8 — Portfolio & Programme Intelligence

Build 8 rolls multiple projects into a programme / portfolio command centre.

## New capabilities
- Programme and portfolio entities
- Project-to-programme assignment
- Portfolio dashboard
- Cross-project RAG heatmap
- Aggregate RAID exposure
- Cross-project dependency hotspots
- Programme-level delivery confidence
- AI programme review
- Systemic risk identification
- Executive portfolio summary
- Programme decisions and intervention recommendations

## Product principle
DeliverIQ should help a programme leader answer:
1. Which projects need intervention?
2. Which risks are systemic across projects?
3. Where are cross-project dependencies creating delivery pressure?
4. What decisions are needed at programme or executive level?
5. What changed across the portfolio since the last review?

AI recommendations are advisory and are grounded in saved project data.
